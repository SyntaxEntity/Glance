# Glance 使用指南

一款面向 GNOME 的低饱和护眼 **Markdown + LaTeX** 阅读器。

## 功能总览

- Markdown 渲染与源码编辑（默认关闭编辑）
- LaTeX 公式渲染与源码编辑
- 工作目录文件树
- 文档大纲跳转
- 暖纸色护眼主题

## 数学

质能方程 $E = mc^2$。

高斯积分：

$$
\int_{-\infty}^{\infty} e^{-x^2}\,\mathrm{d}x = \sqrt{\pi}
$$
